## Installation

Clone the [repository](https://github.com/Durrant lab/reqadence):

```bash
git clone git@github.com:Durrant lab/reqadence.git
```

Install `reqadence` using `pip` after moving into the directory.

```sh
pip install .
```

This will install all dependencies and `reqadence` into your current Python environment.

## Development

We use [pixi](https://pixi.sh/latest/) to manage Python environments and simplify the developer workflow.
Once you have [pixi](https://pixi.sh/latest/) installed, move into `reqadence` directory (e.g., `cd reqadence`) and install the environment using the command

```bash
pixi install
```

Now you can activate the new virtual environment using

```sh
pixi shell
```
